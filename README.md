# 초등학생을 위한 쉬운 역사 사전

러시아어권 다문화 아동의 사회·역사 과목 **'수용 격차'** 해소를 위한 AI 학습 웹서비스입니다.
연세대학교 「러시아어와미디어」 사회혁신과제로 기획·개발했으며, 고등교육혁신원 **Yonsei Social Entrepreneurship Award**를 수상했습니다.

**배포 주소**: https://history-app-2pdcmhaxeockpnznu3rgmz.streamlit.app/

---

## 문제 정의

러시아어권 아동은 한자 기반 배경지식이 없어 '농경', '건국', '전성기' 같은 교과 어휘를 유추하지 못합니다.
일상 회화는 가능해도 '학습 언어'에서 막히는 것이 핵심 문제였습니다.

기존 대안도 한계가 뚜렷했습니다.
- 범용 기계번역은 '무위자연'을 `Му-ви-джа-ён`처럼 **음역만 할 뿐 의미를 풀어주지 않습니다.**
- 생성형 AI는 쓸 수 있지만, 매번 "초등학생 수준으로 쉽게 설명해 줘"라고 **프롬프트를 작성하는 피로**와 **로그인·결제 장벽**이 있습니다.

> 현장 조사에서 아동 전원(4명)이 프롬프트 작성에 피로를 호소했고, 전원이 유료 버전을 쓰지 못하는 상태였습니다.
> 그래서 **프롬프트를 백엔드에 내재화한 무료·무로그인 서비스**로 설계했습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 교과서 사진 판독 | 사진 업로드 → Gemini Vision으로 텍스트 인식 |
| 쉬운 언어 변환 | 어려운 어휘 5개를 자동 추출해 초등 저학년 수준 일상어로 4~5줄 설명 |
| 한자 비노출 설계 | 한자를 직접 보여주지 않고 단어가 만들어진 원리를 옛날이야기처럼 풀이 |
| 사전 링크 병기 | 단어별 국어사전·한러사전 링크로 AI 답변을 즉시 교차 검증 |
| 구글 이미지 연동 | 응답에서 키워드를 추출해 실제 사진 검색 링크 제공 |
| 교과서 리마인드 | 교과서 원문 문장을 인용한 뒤 배운 뜻으로 다시 풀어주는 항목을 고정 출력 |
| 오늘의 단어장 | 세션에 풀이를 누적하고 `.txt`로 내려받아 오프라인 복습 |
| 추가 질문 | 별도 입력칸으로 궁금한 점을 이어서 질문 |

## 현장 검증

안산 고려인문화센터 '아리랑'에서 통제집단(구두 설명)/실험집단(웹사이트 사용) 교차 테스트를 진행했습니다.
동일 난이도 역사 어휘 5문항 기준 **평균 25점 → 95점**으로 향상되었습니다.

> ⚠️ 표본 4명(초등 4~6학년), 피험자 내 설계로 진행한 파일럿 실험입니다.
> 수업 시간(각 30분)과 휴식(20분)을 통제하고 문항 난이도를 맞췄으나, 순서 효과 등 설계상의 한계가 남아 일반화에는 무리가 있습니다.

## 사용자 피드백 기반 개량 이력

현장 인터뷰를 반복하며 세 차례에 걸쳐 수정했습니다.

- **타겟 재정의** — 초기 기획은 수학이었으나, 봉사자 인터뷰에서 실제 장벽은 사회·역사의 추상적 한자어임을 확인하고 과목을 전면 변경
- **한자 표기 제거** — 한자에 대한 거부감이 예상보다 크다는 피드백을 받아 한자 노출을 없애고 뜻풀이 중심으로 전환
- **이미지 방식 교체** — AI 생성 이미지가 한국 고유명사를 인식하지 못하는 오류가 잦아, 구글 이미지 검색 연동으로 변경(속도·직관성 개선)
- **서비스명 변경** — '다문화 가정 학생을 위한'이라는 명칭이 낙인 효과를 줄 수 있다는 의견을 반영
- **체감 속도 개선(v4.0)** — 약 30초의 로딩 지연 지적을 받아 스트리밍 출력을 도입하고, 업로드 이미지를 긴 변 1536px로 압축해 전송량 축소
- **출력 안정화(v4.0)** — 복습 항목이 나올 때와 안 나올 때가 있다는 피드백을 받아 고정 출력으로 승격하고, temperature를 0.2로 낮춰 양식 변동성 완화

## 기술 스택

- **Python / Streamlit** — 프론트엔드 및 배포
- **Google Gemini API (gemini-2.5-flash)** — 멀티모달 판독 및 텍스트 생성, 스트리밍 응답
- **Pillow** — 업로드 이미지 리사이징·JPEG 변환
- API 키는 Streamlit Secrets로 관리

## 알려진 한계

- Streamlit 세션 특성상 새로고침·창 종료 시 단어장이 소실됩니다. 수업 종료 전 `.txt` 저장을 안내하는 방식으로 대응 중입니다.
- 영구 저장과 개인화 복습을 위해서는 프론트엔드 분리(Next.js) 및 로컬 스토리지 연동이 필요하며, 향후 과제로 남아 있습니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

`.streamlit/secrets.toml`에 `GEMINI_API_KEY`를 설정해야 동작합니다.
